# Sokoban Push

Free single-file HTML5 sokoban. Push every wooden crate onto its glowing target
across 12 handcrafted warehouse levels — 1 push at a time, no pulling, crates
that hit a wall or another crate refuse to budge. One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/sokoban-push/

- 12 verified levels (every level machine-solved; difficulty ramps from teaching
  pushes to order-planning depots), star ratings vs par, per-level best saved
- Undo (U, unlimited) + restart (R), moves & pushes counters
- Keyboard (arrows/WASD) + touch (on-screen pad, swipe), canvas scales to fit
- Warehouse visuals: brick walls, concrete floor, forklift-imprinted crates,
  glowing goal markers, push-squeeze animation, level-select map screen
- Procedural WebAudio sounds (step / push / crate-locked / win / reject) with
  mute toggle, progress in localStorage
- Single-file HTML5 (no external assets, no CDN, no tracking), works offline
  once loaded
